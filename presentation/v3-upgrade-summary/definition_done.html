07 / RELEASE ACCEPTANCE

Definition of Done

Release candidate diterima hanya bila bukti teknis, produk, dan operasional tersedia—bukan hanya karena homepage dapat dimuat.

Security

Auth, ownership, upload validation, secret boundary.

Data

Migration idempotent, existing data preserved, backup note.

Marketplace

Browse, search, detail, favorite, create, report end-to-end.

Trust

Verification and moderation states consistent and auditable.

Messaging

Conversation membership, pagination, context, rate limit.

UX

Mobile-first, no overflow, loading/empty/error/success states.

Accessibility

Semantic HTML, keyboard focus, labels, contrast, alt text.

SEO

Metadata, canonical, sitemap, robots, valid structured data.

Performance

Paginated lists, optimized images, measured payload/bundle.

Operations

Health, logs, smoke tests, environment matrix, observability.

Testing

Baseline plus critical journeys and security regressions.

Git & rollback

Focused commits, reviewed SHA, rollback command and notes.
