06 / RELEASE CONTROL

Production runbook

Deploy secara staged. Setiap langkah menghasilkan bukti yang dapat direview sebelum langkah berikutnya dibuka.

01

Freeze & baseline

Branch, SHA, clean tree, `npm ci`, test baseline.

02

Environment

Audit variable dan secret; pastikan dev mode nonaktif.

03

Backup & migration

Snapshot, staging clone, idempotent migration, rollback note.

04

Pre-deploy checks

Test, syntax, API errors, auth boundary, upload policy.

05

Staging canary

Smoke test listing, search, auth, storage, chat, admin.

06

Production smoke

Health, API contract, browser QA, critical journeys.

07

Observe window

Exceptions, latency, 4xx/5xx, OTP, upload, database.

08

Rollback ready

Stop rollout, preserve logs, restore last healthy release.

RELEASE GATEHealth hijau saja tidak cukup. Release diterima hanya setelah security, migration, browser QA, critical journeys, observability, dan rollback diverifikasi.
