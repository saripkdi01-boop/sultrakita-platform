05 / OPEN RISKS

Hardening awal bukan security completion.

Gap berikutnya harus ditutup sebelum fitur mutation dan scale production diperbesar.

Authorization & ownership

Bearer session, `req.user`, dan pemeriksaan kepemilikan untuk listing, favorite, comment, serta profile.

OTP abuse controls

Rate limit khusus IP/nomor, invalidasi challenge lama, dan delivery observability.

Upload & durable storage

Magic-byte validation, cleanup saat gagal, URL safety, dan object storage production.

Runtime parity

Business service yang konsisten antara Express dan Cloudflare Worker untuk mencegah feature drift.

Conversation membership

Hanya buyer/seller terkait yang dapat membaca atau mengirim pesan pada conversation.

Security regression tests

Test wajib untuk impersonation, OTP lockout, upload, admin boundary, dan unauthorized mutation.
