# Aset logo resmi PSI

Letakkan berkas logo **resmi** (dari folder `psi-logo-aset/` milik pengurus) di sini,
atau jalankan `npm run logo` dengan `PSI_LOGO_DIR=/path/ke/psi-logo-aset`.

| Berkas | Dipakai untuk |
| --- | --- |
| `logo-horizontal-warna.png` | Header (latar terang) |
| `logo-horizontal-putih.png` | Header/footer latar gelap atau merah |
| `logo-vertikal-warna.png` | Halaman profil (latar terang) |
| `logo-vertikal-putih.png` | Footer / blok latar gelap |
| `logo-kepala-merah.png` | Favicon & ikon aplikasi |

Situs **tidak** membuat logo tiruan atau placeholder. Selama berkas di atas belum ada,
header hanya menampilkan nama situs sebagai teks biasa.
