# PSI Kendari — Partai Super TBK

Situs berita & profil PSI (Partai Solidaritas Indonesia) wilayah Kota Kendari dan sekitarnya,
Sulawesi Tenggara. Next.js (App Router) + TypeScript + Tailwind CSS, SSG + ISR.

> README lengkap ditulis pada Fase 5. Lihat `.env.example` untuk konfigurasi.

## Jalan lokal

```bash
npm install
cp .env.example .env.local
npm run dev
```
