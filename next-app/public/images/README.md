# Slot Foto Identitas Kendari — Homepage `/`

Folder ini berisi **slot foto** untuk section identitas Kendari di homepage.
Setiap slot bersifat **opsional**: bila file belum ada, halaman otomatis
menampilkan fallback gradasi CSS "Teluk Senja" yang tetap indah (komponen
`components/kendari/ImageSlot.tsx`).

## Aturan

- **Hanya foto asli berlisensi** (milik sendiri / izin tertulis / domain publik).
  Jangan menaruh foto hasil unduhan acak dari internet.
- Format: JPG/WebP, landscape, ≤ 400 KB per file bila memungkinkan.
- Setelah file ditambahkan, halaman otomatis menampilkannya — tanpa perubahan kode.
